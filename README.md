# Final Project — Vocational Training (Web Development)

This repository contains my final project for the Vocational Training in Web Development program.

## Project Purpose

The project simulates a **medical clinic management system**, where different user roles (patients, doctors, receptionists, and administrators) can interact with the platform.  
Its goal is to **manage appointments, invoices, and user authentication** efficiently, providing a complete web solution that connects the backend (Symfony) with the frontend (Angular).

It was designed to demonstrate my skills in **full-stack web development**, database management, and the use of **modern frameworks and tools** in a professional environment.

## Features

- **User authentication and roles** (patients, doctors, receptionists, admins).  
- **Appointment management**: schedule, update, and manage appointments.  
- **Invoice generation and tracking**.  
- **Database integration** with MySQL.  
- **Dockerized environment** for deployment.  
- **Frontend** built with Angular for a modern and responsive user interface.  
- **Backend** built with Symfony to handle business logic and data flow.

## Project Structure

- `Symfony/` — Backend code: controllers, entities, routes, and business logic.  
- `Angular/` — Frontend application: components, services, routes, and interfaces.  
- `bbdd/` — Database scripts and related files.  
- `documentation/` — Additional documentation such as diagrams and specifications.  
- `Dockerfile`, `docker-compose.yml`, `php.ini` — Configuration files for the Dockerized development environment.  
- `.gitignore`, `composer.json` — Repository and dependency configuration files.  

## Requirements

- PHP >= 8.x  
- Composer  
- Node.js / npm  
- Docker & Docker Compose
